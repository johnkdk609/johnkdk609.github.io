<a href="https://www.acmicpc.net/problem/11403" target="_blank">백준 11403번 경로 찾기</a> 문제는 플로이드 워셜 개념을 활용해야 하는 문제이다.

우선 Floyd-Warshall 알고리즘이 뭔지 알아보고, 그 다음으로는 해당 문제의 해결 방법에 대해 기술해보겠다.

## Floyd-Warshall 알고리즘이란?

Floyd-Warshall은 모든 정점 쌍 간의 최단 거리를 구하는 알고리즘이다. 즉, i번 정점에서 j번 정점으로 가는 최단 경로의 길이를 모든 쌍에 대해 한 번에 계산하는 알고리즘이다.

<br>

시간복잡도는 ```O(N³)```이다. 정점 수가 N개일 때, 모든 중간 정점 k를 기준으로 각 출발 정점 i와 도착 정점 j에 대해 세 번의 반복문이 필요하기 때문이다.

<br>

핵심 아이디어는 "정점 k를 거쳐서 가는 경로가 더 짧은가?" 이다. 즉, ```dist[i][j]```는,

```java
dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
```

의 방식으로 모든 경로를 거쳐가는 최단 경로를 찾아나가는 것이다.

<br>

## 백준 11403번 해결

문제의 핵심은 '최단 거리 자체는 안 중요하다'는 것이다. 단지 경로가 존재하는지만 알면 된다. (즉, 도달 가능 여부)

입력은 인접 행렬로 주어졌다. ```graph[i][j] = 1;``` → i에서 j로 직접 가는 간선이 있다.

i에서 j로 직접 가거나, 중간 정점들을 거쳐서라도 갈 수 있으면 1, 아니면 0 이다.

<br>

적용한 로직은 다음과 같다.

```java
if (graph[i][k] == 1 && graph[k][j] == 1) {
    graph[i][j] = 1;
}
```

이는 즉, "i에서 k로 갈 수 있고, k에서 j로 갈 수 있다면, 결국 i에서 j로도 갈 수 있다." → ```graph[i][j] = 1;```

<br>

결국 해당 문제에서는 최단 거리가 아니라 '경로 유무'만 필요하니까, 굳이 ```INF```, ```Math.min(...)```, 거리 누적값 등을 안 써도 된다.

```boolean```이나 ```0/1``` 값만 써서 간단히 처리 가능하다.

<br>

답안 코드는 다음과 같다.

```java
import java.io.*;
import java.util.*;

public class Main {

    static int N;
    static int[][] grid;

    public static void main(String[] args) throws IOException {

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());

        grid = new int[N][N];
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < N; j++) {
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        floydWarshall();

        StringBuilder sb = new StringBuilder();
        for (int r = 0; r < N; r++) {
            for (int c = 0; c < N; c++) {
                sb.append(grid[r][c] > 0 ? 1 : 0).append(' ');
            }
            sb.append('\n');
        }

        System.out.println(sb.toString());
    }

    private static void floydWarshall() {
        for (int k = 0; k < N; k++) {
            for (int r = 0; r < N; r++) {
                for (int c = 0; c < N; c++) {
                    if (grid[r][k] == 1 && grid[k][c] == 1) {
                        grid[r][c] = 1;
                    }
                }
            }
        }
    }
}
```

<br>

그러면 이 문제를 BFS로 풀면 안 될까 궁금할 수 있다. 풀 수는 있다. 하지만,

* BFS를 이용하려면, 모든 정점 i에 대해 BFS를 N번 돌려야 한다.
* 시간복잡도: ```O(V * (V + E))```
* 이 문제에서는 정점 수 N이 최대 100 → ```O(N³)``` 플로이드 워셜이 괜찮은 선택
