Java에서 <b>사전(Dictionary) 자료형은 Map 자료구조를 구현함으로써 사용할 수 있다.</b>

```java
Map<자료형, 자료형> map = new HashMap<>();
```

위의 구조로 구현한다. 이를 위해서는 최상단에 ```import java.util.*;```을 선언해둬야 한다.

<br>

가령 다음과 같이 키(key)는 String, 값(value)은 Integer인 Map을 생성했다고 해보자.

```java
Map<String, Integer> map = new HashMap<>();
```

<br>

값 추가는 다음과 같이 한다.

```java
map.put("Apple", 3);
map.put("Banana", 5);
map.put("Orange", 2);
```

<br>

값 가져오기는 다음과 같다.

```java
System.out.println("Apple 개수: " + map.get("Apple"));

// Apple 개수: 3
```

<br>

키 존재 여부 확인 방법은 다음과 같다.

```java
System.out.println("Mango 있나? - " + map.containsKey("Mango"));

// Mango 있나? - false
```

<br>

값 존재 여부 확인 방법은 다음과 같다.

```java
System.out.println("값 5가 있나? - " + map.containsValue(5));

// 값 5가 있나? - true
```

<br>

값 수정 방법은 다음과 같다.

```java
map.put("Apple", 10);
```

<br>

키 삭제 방법은 다음과 같다.

```java
map.remove("Banana");
```

<br>

entrySet() 을 사용한 전체 순회 방법은 다음과 같다.

```java
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " : " + entry.getValue());
}

/*
Apple : 10
Orange : 2
*/
```

<br>

keySet() 을 사용한 전체 순회 방법은 다음과 같다.

```java
for (String key : map.keySet()) {
    System.out.println(key + " : " + map.get(key));
}

/*
Apple
Orange
*/
```

<br>

## Programmers - 완주하지 못한 선수

Programmers 사이트의 <a href="https://school.programmers.co.kr/learn/courses/30/lessons/42576?language=java" target="_blank">완주하지 못한 선수</a> 문제에서는 Map 자료구조를 사용해야 한다.

우선 답안 코드는 다음과 같다.

```java
import java.util.*;

class Solution {
    public String solution(String[] participant, String[] completion) {
        String answer = "";
        
        Map<String, Integer> map = new HashMap<>();
        
        for (String person : participant) {
            map.merge(person, 1, Integer::sum);
        }
        
        for (String person : completion) {
            map.merge(person, -1, Integer::sum);
        }
        
        for (Map.Entry<String, Integer> e : map.entrySet()) {
            if (e.getValue() > 0) {
                answer = e.getKey();
                break;
            }
        }
        
        return answer;
    }
}
```

<br>

위 코드를 보면, ```map.merge(person, 1, Integer::sum);``` 혹은 ```map.merge(person, -1, Integer::sum);```과 같은 다소 익숙하지 않은 코드가 있다.

이는 Java8 부터 추가된 Map 값 병합 메서드이다. 키가 없으면 값을 넣고, 키가 있으면 기존 값과 새 값으로 연산을 적용하는 기능이다. 카운팅이나 합계 누적 같은 경우 특히 깔끔하다.

<br>

기본 문법은 다음과 같다.

```java
map.merge(key, newValue, (oldValue, newValue) -> ...연산...);
```

이때 ```key```는 대상 키이고, ```newValue```는 새로 넣을 값, ```(oldValue, newValue)```는 키가 있으면 실행되는 람다 (기존 값, 새 값)식이다.

<br>

카운트하는 예제를 보자.

```java
Map<String, Integer> countMap = new HashMap<>();

// "Apple" 없으면 1 넣고, 있으면 기존 값 +1
countMap.merge("Apple", 1, (oldVal, newVal) -> oldVal + newVal);
countMap.merge("Apple", 1, (oldVal, newVal) -> oldVal + newVal);

System.out.println(countMap);

// {Apple=2}
```

<br>

이때 ```Integer::sum```을 사용함으로써 더 간결하게 작성할 수 있다.

```(oldVal, newVal) -> oldVal + newVal``` 대신 ```Integer::sum``` 메서드 참조를 할 수 있는 것이다.

```java
countMap.merge("Apple", 1, Integer::sum);
countMap.merge("Banana", 1, Integer::sum);
System.out.println(countMap);

// {Apple=1, Banana=1}
```

<br>

키가 없으면 ```newValue```가 그대로 들어간다.

```java
countMap.merge("Mango", 5, Integer::sum);

// 없으니 5로 저장
```

<br>

이 방법의 장점은, ```containsKey()``` + ```put()``` 조합을 한 줄로 줄인다는 것이다. 초기값 설정과 업데이트 로직을 통합하고, 동시성 컬렉션(ConcurrentHashMap)에서도 안전하게 사용할 수 있다.
